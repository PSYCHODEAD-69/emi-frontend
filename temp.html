EMI — Fix Legacy Model Links

One-time tool for products that were bulk-imported straight into KV (via migrate.html) before the admin panel's model picker existed. Those products may have their compatible models stored as plain text (e.g. Ola S1 Pro) instead of linked to the actual model in the models list (e.g. ola-s1-pro) — which is why deleting/removing a model from a product doesn't work, and re-adding one from the admin panel appears to duplicate it instead of replacing it. This matches the old text values against your current models list by name and relinks them. Delete this file once you've run it successfully — it's not meant to stay in the repo.

2. Preview (dry run — makes no changes)

3. Apply fix

Relinks every product's model text to the correct model in your list. Values that don't match any current model name are left unlinked and reported in the log — nothing is guessed. Safe to run more than once; products that already link correctly are left untouched.
